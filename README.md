# Straitgate Secondary Standalone

Standalone React/Vite page for the Straitgate secondary school revamp.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Main page component: `src/SecondarySchoolPage.jsx`
- Main stylesheet: `src/SecondarySchoolPage.css`
- Static assets are stored in `public/assets`
- Flaticon icons require attribution; credit links are included in the footer.
